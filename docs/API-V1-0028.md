# HomeGuard-S3 API v1

## GET `/api/v1/state`

Returns the complete current state required by the web and Android clients.

64-bit counters and timestamps are encoded as JSON strings.

## GET `/api/v1/build`

Returns firmware provenance:

- project;
- build;
- semantic version;
- board;
- module;
- ESP-IDF version;
- Git revision;
- build timestamp.

## POST `/api/v1/command`

Request:

```json
{
  "request_id": "UUID",
  "actor": "android:device-id",
  "command": "valve.close",
  "target": "cold",
  "value": ""
}
```

Supported commands in Build-0028:

```text
security.arm_home
security.arm_away
security.disarm
light.set
valve.close
valve.open
valve.clear_latch
```

Responses:

```text
accepted
duplicate
rejected
unauthorized
invalid
hardware_fault
```

Authentication remains mandatory for production firmware. The portable command
router validates idempotency and safety state, while the real HTTP layer must
validate the Bearer token before calling it.
