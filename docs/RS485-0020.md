# RS-485 / Modbus RTU

Default configuration:

```text
UART1
9600 baud
8 data bits
no parity
1 stop bit
half duplex
```

GPIO:

```text
DE/RE → GPIO16
TX    → GPIO17
RX    → GPIO18
```

The first portable helper creates Modbus function 03 requests.
Register maps remain device-specific and must be added only after the exact
220 V energy meter model is selected.
