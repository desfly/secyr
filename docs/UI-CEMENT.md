# HomeGuard-S3 UI cement rules

These rules are approved and must not be silently changed by later UI work.

## Bruce artwork — HARD REQUIREMENT

The canonical Bruce reference for both the Web UI and Android app is the approved user-supplied image where **both fists/hands are visible in the frame**.

Required:
- both fists/hands visible;
- lower fist must not be cropped out;
- no blur or softening;
- no stretching or altered facial/body proportions;
- preserve the approved framing/aspect ratio;
- `web/bruce.jpg` must use this approved two-fist composition;
- Android Bruce artwork/icon usage must use the same approved two-fist source/composition unless the user explicitly approves another asset.

Rejected variants:
- one fist only;
- missing hand;
- cropped lower fist;
- blurred/softened image;
- distorted proportions;
- any automatic crop that removes either fist.

This is a cemented UI rule. Changing it requires explicit user approval.
