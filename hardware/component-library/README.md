# HomeGuard-S3 Component Library

Еталонна бібліотека фізичних компонентів проєкту HomeGuard-S3.

## Правило бібліотеки

**1 компонент = 1 односторінкова картка:** фото конкретного фізичного компонента, точна назва/маркування, перевірювані параметри та ключові піни/підключення.

Не підміняти компонент іншим модулем лише через однаковий чип. Якщо фото, маркування або параметр не підтверджені — не домислювати.

## HG-COMP-008 — зафіксовано

- Плата релейного модуля з оптопарами.
- 4 незалежні релейні канали.
- Живлення/котушки: **5 V** — за даними користувача.
- На наданому фото видно 4 сині електромеханічні реле, 4 оптопари, індикаторні елементи, вхідний роз'єм керування та по 3 гвинтові контакти на кожен релейний канал.
- Вихід кожного каналу: перекидний контакт типу **NO / COM / NC**.
- Точний порядок керуючих пінів, active-HIGH/active-LOW, допустимий струм контактів і наявність окремого JD-VCC не фіксувати без читабельного маркування/зворотного фото.
- Еталонна фотокартка HG-COMP-008 має використовувати саме фото, надане користувачем, без підміни іншим схожим модулем.
